03 / Tables

Tables that adapt to the document.

Switch between fitted, wide, fullscreen, and compact layouts so large AI-generated tables remain readable instead of being squeezed into a narrow chat column.

04 / Reading settings

Reading settings that adapt to you.

Adjust text size, spacing, appearance, code presentation, and reading style—including dyslexia-friendly and fixation-guided Fast Reading options—without changing the original conversation.

  • Default
  • Serif
  • Dyslexia-friendly
  • Fast Reading

Fast Reading uses fixation-guided letter emphasis to support faster scanning.

Fast Reading uses the open-source Fast Font project by Born2Root, available under the MIT License.

05 / Highlights

Mark important passages and find them again.

Select and highlight text while you read, then return to it later. Highlights stay with the conversation in ReadBooster and remain available in both Continuous Document and Focus views.

  • Choose from several accessible highlight colours.
  • Review saved passages in the highlights overview.
  • Move to the previous or next highlight.
  • Recolour or remove a highlight when it no longer fits.

06 / Stickers

Local notes that remain connected to the document.

Attach local Stickers to relevant sections, move or collapse them, and use directional indicators to find saved notes above or below your current position.

Highlight a passage when the text itself matters. Add a Sticker when you want to leave your own note for a section.

Privacy by design

The document is built where the conversation already is.

ReadBooster accesses page content locally to render the document view. It does not upload your conversation content to a ReadBooster server.

  • Conversation formatting happens locally in the browser.
  • Reading fonts, including Fast Reading, are bundled locally with the extension.
  • Highlights are stored locally with the selected text and limited context needed to find the passage again.
  • Preferences, custom section titles, and Stickers are also stored locally in your browser.
  • No ReadBooster account is required, and the only general browser permission is storage.
  • Feedback is sent only when you deliberately submit the Tally form.
  • You decide what text or screenshots you include.

Reference

ReadBooster FAQ

What does ReadBooster do?

ReadBooster transforms supported AI conversations into structured documents that are easier to read, navigate, highlight, annotate with Stickers, print, copy, and revisit. It includes Document and Focus views, an outline, table and code controls, and adaptable reading settings.

What is the difference between highlights and Stickers?

Highlights mark text that already exists in the conversation. Stickers attach a note you write to a section. Both are stored locally in your browser.

Are highlights sent anywhere?

No. Highlighted text and the limited context needed to restore it are stored locally in your browser and are not sent to ReadBooster servers.

Do highlights sync between devices?

No. ReadBooster 0.7.3 stores highlights locally. Account-based or cross-device synchronisation is not currently included.

Which AI platforms are supported?

ChatGPT, Google Gemini, Mistral AI, and Claude are supported in the current release.

Why are the Firefox and Chrome versions different?

Browser stores publish updates independently. Version 0.7.3 is available on Firefox, while the Chrome Web Store currently offers version 0.6.9. ReadBooster 0.7.3 is not yet available there.

What reading styles does ReadBooster offer?

ReadBooster offers Default, Serif, Dyslexia-friendly, and Fast Reading styles. Fast Reading uses fixation-guided letter emphasis, while text size and spacing can be adjusted independently. These settings change only the local document view and do not modify the original conversation.

Does ReadBooster upload my conversations?

No. ReadBooster processes supported conversation pages locally to render its document view and does not send full conversation content to a ReadBooster server. Feedback is separate and opens an external Tally form only after you explicitly choose it.

Is it free?

The current testing release is free. This is not a permanent pricing commitment, and later availability may change.

Does it modify the original AI conversation?

No. ReadBooster creates a separate reading presentation in the browser. Display choices such as section renaming apply to the ReadBooster view, not to the source conversation.

Can I print or save the document?

Yes. Print Studio prepares AI conversations as clean documents for printing or saving as PDF, with controls for sections, highlights, Stickers, layout, and document formatting.

Is ReadBooster affiliated with the supported AI providers?

No. ReadBooster is an independent browser extension and is not affiliated with or endorsed by OpenAI, Google, Mistral AI, or Anthropic.

Is ReadBooster open source?

Yes. Avi started ReadBooster and currently maintains it as an open-source AviCloud project licensed under the Mozilla Public License 2.0. You can explore the project on GitHub and read the complete MPL 2.0 licence text.

Can I request support for another AI platform?

Yes. Search existing issues, then use the platform request form. Explain which service you use, what kinds of conversations you read there, and where ReadBooster could help. Requests guide priorities but do not guarantee implementation.

Can I contribute?

Yes. You can help by reporting problems, sharing ideas, testing changes, improving documentation, or contributing code. Developers and technical contributors can also work on accessibility, tests, fixes, and platform adapters. The contributor guide explains how to get started.
