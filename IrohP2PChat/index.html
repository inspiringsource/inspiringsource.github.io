Engineering portfolio project

Iroh P2P Chat

Temporary peer-to-peer rooms with a native terminal host and browser-based guests.

This is a focused architecture experiment, not a replacement for Mattermost, Slack, or enterprise collaboration platforms.

Overview

Iroh P2P Chat creates a temporary peer-to-peer chat room where a host runs the application locally and participants join through a browser invitation. The host process owns the room, while browser guests connect without installing the native client.

“Exploring how far a chat system can be simplified when accounts, databases, permanent servers, and message history are removed.”

Problem / Motivation

Traditional messaging systems often depend on several long-running components:

  • Application servers
  • Databases
  • Authentication systems
  • Persistent infrastructure

Those components support important capabilities such as administration, retention, integrations, and reliable long-term availability. This project explores a different design space: what the system can become when the session itself is temporary and those durable requirements are deliberately removed.

The native client and browser client share a Rust protocol core. It handles ticket parsing, message structures, signing, and verification; the browser build compiles that same core to WebAssembly instead of recreating the protocol in TypeScript.

GitHub Pages only distributes the static browser client: HTML, CSS, JavaScript, and WebAssembly. It does not host the room, store messages, or keep the chat session alive. Once loaded, the browser connects through Iroh to the locally running host process.

Features

  • Rust + Iroh
  • Ratatui terminal interface
  • Browser client via WebAssembly
  • Signed messages
  • Temporary identities
  • Memory-only sessions
  • Invitation-based joining
  • Owner-controlled lifecycle
  • No accounts or database
  • No persistent message history

Demo / Usage

The owner starts a room from the native terminal application. Guests receive the generated invitation link and join with an ordinary browser.

Host

$ iroh-p2p-chat host --name Alice

Guest

Open the invitation link in a browser, choose a nickname, and join the temporary room.

Iroh P2P Chat is an experimental portfolio project. It does not claim anonymity, guaranteed deletion, or production readiness. Invitations can be forwarded, and content may still be copied or retained by participants or their devices.
