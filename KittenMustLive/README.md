# Kitten Must Live website

Static promotional site for Kitten Must Live, published as part of the Inspiring Source GitHub Pages site:

https://inspiringsource.github.io/KittenMustLive/

## Local preview

Start a static server from the parent `inspiringsource.github.io` repository so the subpath matches production:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/KittenMustLive/`.
